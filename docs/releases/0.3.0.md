# Release Notes: v0.3.0

Version 0.3.0 introduces the application-facing Memory API. This is a
breaking release for Python consumers.

## Python migration

The Python `IndexStore` binding is removed. Code such as:

```python
store = lint_ai.IndexStore()
store.upsert("doc-1", "Docker install guide")
store.query("docker", 5)
```

should migrate to:

```python
memory = lint_ai.Memory(path="./memory-index")
memory.add(
    "request-1",
    "user-1",
    "session-1",
    [{"role": "user", "content": "Docker install guide"}],
)
memory.search("docker", "user-1", 5)
```

For a separately running server, use `lint_ai.RemoteMemory` with the same
methods. The low-level Rust `IndexStore` API remains available for advanced
Rust integrations, but it is not the application-facing memory contract.

## Memory API

`Memory` and `RemoteMemory` provide `add`, `search`, `get`, `list`, `update`,
`delete`, and `refresh`. The HTTP implementation is available under the
versioned `/v1/memories` routes. Existing legacy HTTP routes remain available
for compatibility.
