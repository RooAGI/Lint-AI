# Release Notes: v0.6.2

Date: 2026-10-16

Version 0.6.2 adds an observe-only hook setting for projects that want to
capture provider sessions without automatically retrieving and injecting
memory into prompts.

## Observe-only hooks

- Added `[hooks].observe_only` in `.membrick/settings.toml`.
- Applied the setting to Claude Code, Codex, Gemini CLI, AGY, OpenClaw,
  Hermes, and Roo Runtime hooks. Muse hooks already capture without automatic
  retrieval.
- Kept explicit MCP searches available when observe-only mode is enabled.
- Added unit coverage for capture and retrieval behavior, including the Hermes
  plugin.

## Upgrade notes

Upgrade the Membrick executable and set `observe_only = true` under `[hooks]`
in `.membrick/settings.toml` to disable automatic hook retrieval while
continuing to capture sessions.
