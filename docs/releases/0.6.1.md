# Release Notes: v0.6.1

Date: 2026-10-16

Version 0.6.1 adds a workflow for reviewing search quality and enriching
existing source documents through MemoryService.

## Search review and document enrichment

- Added `review_search` to retrieve paginated unreviewed searches or inspect a
  specific recorded search.
- Added `search_feedback` to associate an overall usefulness label and a
  relevance judgment for each returned document with its search.
- Added `enrich_doc` to apply reviewed changes to a cited source document while
  retaining the original observations and validating the document revision.
- Added dashboard views for submitted search feedback and an offline evaluation
  tool. Feedback supports evaluation; it does not immediately change ranking.

See the [MCP tools](../mcp.md),
[document enrichment plan](../document-enrichment-plan.md), and
[observability guide](../observability.md).

## Upgrade notes

Upgrade the Membrick executable and restart provider MCP sessions to expose the
new tools. Existing recorded searches remain available for review. Search
feedback is optional when results answer the query; agents should submit it
when results are inadequate or miss important context.
