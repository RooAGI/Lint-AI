# Contact

Lint-AI is built by [RooAGI](https://www.rooagi.com). The fastest way to get
help or start a conversation is through the project repository:

- [Email the project maintainer](mailto:lw@rooagi.com)
- [Ask a question or report a problem](https://github.com/RooAGI/Lint-AI/issues)
- [Review the source and current work](https://github.com/RooAGI/Lint-AI)
- [Visit RooAGI](https://www.rooagi.com)

When filing an issue, include the Lint-AI version, interface used (CLI,
Python, HTTP, MCP, or agent integration), operating system, and a minimal
reproduction when possible. Do not include private prompts, credentials, or
user memory content in a public issue.
