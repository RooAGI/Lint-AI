# lint-ai — memory recall for OpenClaw

The `handler.js` in this directory is a thin wrapper: on `agent:bootstrap` it
serializes the event to `lint-ai --openclaw-hook bootstrap` (JSON on stdin),
applies the `bootstrapFiles` returned on stdout to the live event, and fails
open on any error. On `message:received` it remembers the latest user text per
session so the bootstrap query can target the user's actual request.

All lifecycle logic (retrieve, inject, capture) lives in the lint-ai Rust
binary, which is stateless: idempotency comes from stable document IDs in the
memory store, like the Claude/Codex hooks. Compaction capture is intentionally
not wired yet: the compaction hooks were not observed on a live host.
