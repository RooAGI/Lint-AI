# Release Notes: v0.2.1

Date: 2026-09-17

Version 0.2.1 adds the local operational dashboard and tightens the server's
local-use boundary while preserving the v0.2.0 indexing and retrieval changes.

## Dashboard

- Added a localhost dashboard for IndexStore health, query activity, latency,
  errors, segment topology, provider integrations, sessions, and tool usage.
- Added provider-aware dashboard views for Claude Code, Codex, Gemini CLI, and
  AGY when their integrations are compiled and have emitted telemetry.
- Added bounded operational telemetry and sanitized lifecycle previews for the
  dashboard.
- Added homepage dashboard screenshots with an interactive sliding carousel.

## Server and security

- The HTTP server remains configurable by loopback address and port, but now
  rejects non-loopback bind addresses at startup.
- `--allow-unauthenticated` is supported for the intended single-user local
  dashboard mode; it cannot make the server network-facing.
- Added loopback bind validation tests and documented the dashboard run path.

## Verification

- Server unit tests pass, including loopback binding validation.
- The dashboard is served at `http://127.0.0.1:8080/dashboard` when the server
  is started with the appropriate provider feature flags.
