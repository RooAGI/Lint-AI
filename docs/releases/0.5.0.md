# Release Notes: v0.5.0

Date: 2026-10-14

Version 0.5.0 changes the bundled agent integration path to a resident local
IPC service. Claude Code, Codex, and other bundled Rust integrations can start
the owner on their first request and communicate without opening a local TCP
listener. The standalone HTTP API remains available for applications and
custom integrations.

## Resident local IPC service

- Bundled Rust MCP adapters and provider lifecycle hooks connect to a
  workspace-specific resident owner over local IPC.
- macOS and Linux use a user-private Unix domain socket. Windows uses a named
  pipe. The resident startup coordination prevents concurrent first requests
  from starting multiple writers for the same workspace.
- The IPC and standalone HTTP listeners use the same API routes and
  `MemoryService` implementation. Only one process should own a workspace's
  on-disk stores at a time.
- The bundled adapters use settings and workspace context to resolve the local
  endpoint; they do not need environment variables to choose the transport.
- Resident diagnostics are written to `~/.membrick/runtime/resident.log` on
  Unix-like systems and `%USERPROFILE%\.membrick\runtime\resident.log` on
  Windows.

See [Local IPC server architecture](../local-ipc-architecture.md) for request
flow, endpoint security, and HTTP compatibility details.

## Transport benchmark

A matched 10-second diagnostic used the same MCP handler and load for loopback
HTTP and Unix-socket IPC, with four search callers and one writer. Each request
opened a fresh connection. Both runs returned no errors, and the last write was
searchable after acknowledgement.

| Transport | Searches/s | Search p50 / p95 / p99 | Writes/s | Write p50 / p95 / p99 |
|---|---:|---:|---:|---:|
| HTTP over loopback TCP | 76.97 | 51.8 / 64.4 / 68.2 ms | 11.15 | 87.9 / 101.7 / 103.4 ms |
| Local IPC over Unix socket | 79.95 | 48.9 / 64.1 / 74.0 ms | 11.75 | 82.0 / 97.4 / 99.8 ms |

This is one short run per transport. The differences are within run variation
and do not establish a throughput advantage. These figures describe the
specific local MCP workload; they do not measure Windows named pipes or a large
production corpus. See the [benchmark report](../http-server-benchmarks.md#matched-http-and-ipc-diagnostic-2026-10-14).

## Upgrade notes

- Existing HTTP clients can continue using the standalone HTTP server.
- Bundled Rust provider integrations use local IPC automatically. No
  environment variable or separately started HTTP server is required for that
  path.
- Do not run the standalone server and resident IPC owner as simultaneous
  writers for the same workspace data.
